The Drake is a strategic two-player board game developed in Java as part of a university course. Inspired by the board game The Duke, the objective is to capture the opponent's Drake unit. Each player controls a set of unique units, each with its own distinct movement pattern.

This project was a major milestone in my Java development journey. It served as a comprehensive exercise where I applied nearly all core and advanced Java concepts, including:

Object-Oriented Programming: Custom unit classes with polymorphic movement logic.

JavaFX: Built an interactive GUI with animations and board visualization.

Multi-threading: Ensured smooth UI updates and responsive gameplay logic.

Networking: Implemented a multiplayer mode over a network.

Working on The Drake taught me the full spectrum of Java, from syntax and object-oriented design to event-driven programming and concurrency. It was both a challenging and rewarding experience that significantly improved my confidence and capability in Java software development.
