A robust multi-layer web application created as a team project for a software engineering course. This system supports the full business workflow for a tobacco distributor, including product management, customer registration, order processing, and stock transfers between warehouses.

We applied a three-layer architecture (presentation, business logic, data access) to ensure maintainability and scalability. My contributions included:

Designing and implementing the backend architecture in Python

Developing REST API endpoints in Flask

Handling database communication using SQLAlchemy

Refactoring the system for clean separation of concerns

Creating UML diagrams and architectural blueprints

This project was an essential experience in building a complete system from analysis and design to implementation and testing, emphasizing teamwork, clean code practices, and scalable architecture.
